# Java Quiz Application 📝

A sleek, desktop-based interactive Quiz Application built using **Java Swing** and **AWT**. This application features a user login system, a timed quiz interface, and a final score calculation screen.

---

## ✨ Features
* **User Authentication:** Simple login screen to capture the player's name.
* **Interactive UI:** Graphical interface designed with Java Swing.
* **Rules Page:** A dedicated screen to outline the quiz guidelines before starting.
* **Dynamic Scoring:** Real-time tracking of correct answers.
* **Visual Assets:** Integrated custom images for a professional look and feel.

## 📂 Project Structure
The repository contains the following core Java classes:
* `Login.java`: The entry point and user authentication screen.
* `Rules.java`: Displays the instructions for the quiz.
* `Quiz.java`: The main gameplay logic and question interface.
* `Score.java`: Final screen displaying the user's performance.

## 🚀 Getting Started

### Prerequisites
* **JDK 8** or higher installed on your machine.
* An IDE (IntelliJ IDEA, Eclipse, or NetBeans) or a terminal.

### Installation & Execution
1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/AKASH-22203/javaquizapplication.git](https://github.com/AKASH-22203/javaquizapplication.git)
    ```
2.  **Navigate to the directory:**
    ```bash
    cd javaquizapplication
    ```
3.  **Compile the application:**
    ```bash
    javac Login.java
    ```
4.  **Run the application:**
    ```bash
    java Login
    ```

## 🛠️ Technologies Used
* **Language:** Java
* **Framework:** Swing, AWT (Abstract Window Toolkit)
